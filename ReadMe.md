## Complexity Reference

### Data Structure Operations Complexity

| Data Structure | Access | Search | Insertion | Deletion | Info |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Array** | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ | Fixed Size Contiguous Memory |
| **Stack** | $O(n)$ | $O(n)$ | $O(1)$ | $O(1)$ | LIFO |
| **Queue** | $O(n)$ | $O(n)$ | $O(1)$ | $O(1)$ | FIFO |
| **Linked List** | $O(n)$ | $O(n)$ | $O(1)$ | $O(n)$ | Dynamic Nodes |
| **Hash Table** | - | $O(n)$ | $O(n)$ | $O(n)$ | $O(1)$ Average With Good Hash Distribution |
| **Binary Search Tree** | $O(n)$ | $O(n)$ | $O(n)$ | $O(n)$ | $O(\log n)$ When Balanced |
| **AVL Tree** | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | Strictly Balanced BST |
| **Red-Black Tree** | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ | Balanced BST |
| **Bloom Filter** | - | $O(1)$ | $O(1)$ | - | Probabilistic Set Membership |

### Sorting Algorithms Complexity

| Algorithm | Best | Average | Worst | Memory | Stable |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Bubble Sort** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | Yes |
| **Insertion Sort** | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | Yes |
| **Selection Sort** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | No |
| **Heap Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | No |
| **Merge Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | Yes |
| **Quick Sort** | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | No |
| **Shell Sort** | $O(n \log n)$ | Gap Dependent | $O(n (\log n)^2)$ | $O(1)$ | No |
| **Counting Sort** | $O(n + r)$ | $O(n + r)$ | $O(n + r)$ | $O(n + r)$ | Yes |
| **Radix Sort** | $O(n \cdot k)$ | $O(n \cdot k)$ | $O(n \cdot k)$ | $O(n + k)$ | Yes |
| **Bucket Sort** | $O(n + k)$ | $O(n + k)$ | $O(n^2)$ | $O(n)$ | Yes |
